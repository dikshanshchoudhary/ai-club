# Demo environment

This directory contains intentionally vulnerable, non-production examples for local demonstrations. Do not deploy them or reuse the sample credentials.

Suggested demo flow:

1. Scan `vulnerable-repo/`.
2. Review `sample-findings.json` in the Findings page.
3. Inspect `sample-terraform/`, `sample-dockerfile/`, and `sample-k8s/`.
4. Generate the executive and technical reports.
